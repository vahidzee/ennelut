# Juan Melara LUTs

## Source

This collection points to Juan Melara's print-film-emulation LUTs:
https://juanmelara.com.au/blog/print-film-emulation-luts-for-download

## How To Acquire

Download the LUT pack from the source page and extract the files into this directory or another local LUT workspace. Review the source page for the intended color pipeline and any usage guidance before applying the LUTs.

## What We Looked Into

We inspected this pack because it contains film-print-emulation LUTs with subtle stylization. It was useful as a qualitative source to think about real-world LUT behavior, but it was not used for the paper's reported quantitative experiments.
