# Wanderlust LUTs

## Source

This collection points to the free Wanderlust log-footage LUTs published by PremiumBeat:
https://www.premiumbeat.com/blog/free-luts-log-footage/

## How To Acquire

Download the LUT pack from the source page, extract the `.cube` files, and place them in this directory or another local LUT workspace.

## What We Looked Into

We inspected this collection as another freely available set of log-footage color looks. It was not used for the paper's reported quantitative experiments.

## Notes

- The LUTs in this collection are `64x64x64`.
